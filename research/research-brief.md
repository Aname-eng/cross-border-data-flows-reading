# 研究简报：跨境数据流论文解析、复核与互动汇报

## 问题与目标

在不改写既有 `content/论文解析.md` 的前提下，完成四项成果：把逐步解析排成可阅读 PDF；把论文问题、动机、定量发现、政策含义、贡献与质疑组织成完整汇报；独立复核企业数据选择是否存在无有限最优问题并给出可闭合的修复；用现实制度和后续研究评估三个扩展的合理性。最终以一个可分支阅读、同时允许线性通读的静态 HTML 网站交付。

## 完成标准

1. `content/论文解析.md` 与来源文件逐字节一致；生成 `deliverables/逐步解析.pdf`。
2. `content/完整汇报.md` 覆盖研究问题、动机、机制、定量结果、政策、贡献、限制和演讲取舍。
3. `content/有限最优复核与修复.md` 明确检查授权集合、企业测度、价格口径，并区分原文、推导和修复建议；提供可运行检查。
4. `content/扩展现实基础.md` 对三个扩展分别给出制度事实、经济机制、模型改动和可检验预测。
5. `docs/` 包含全部正文、公式、来源和三条可选扩展路线；网站可离线打开，关键交互和打印布局通过浏览器检查。
6. README 说明目录、构建、协作和引用边界；仓库完成提交并推送 GitHub。

## 禁止的替换

- 不改动原 `论文解析.md` 的内容、公式、判断强度或章节结构。
- 不把作者报告值写成独立复现结果，不把 NBER 工作论文写成已发表论文。
- 不把对一种字面最优化问题的反例写成对作者所有可能合同解释的定论。
- 不以数值图替代一般性证明，不把修复后的模型冒充原模型。
- 不声称完成开放经济 IRF 复现、结构估计或形式化证明。

## 已知失败模式与对应检查

- **版本错置：**逐项核对 AFA 报告、2023 初版和 2025 修订版。
- **连续体与非竞争性混淆：**分别核对单企业选择集、单位测度聚合和数据商收入式。
- **价格口径混淆：**区分每单位工作数据价格、相同数据包的许可费和企业安装成本。
- **定量结果过度解读：**只报告原文图表支持的方向和区间，不编造点估计。
- **网页内容缺失：**构建脚本检查正文标题、路线数、公式容器和 PDF 链接。
- **PDF 公式缺失：**渲染后抽查文本、页数和代表性公式页面。

## 所需证据

- 原文页码、公式和脚注；来源稳定 URL；定量结果对应图表/章节。
- 有限最优的一般指数推导、可执行数值例和修复后的 coercivity 条件。
- 每个扩展至少一项制度事实与一项学术来源，并标明其支持的是动机而非模型正确性。
- 构建日志、测试输出、浏览器截图或 DOM 检查结果。

## 升级触发

如果复核发现原文存在明确的企业采购上限、非线性许可合同或不同于现有解析的价格定义，必须收窄或撤回“无有限最优”结论。如果修复会改变论文核心数据市场对象，则在成果中并列备选闭合方式，不把其中一种说成作者本意。

## 阻塞路线规则

无法取得全文或不能定位原文页码的后续论文，只能作为检索线索，不能支持正文论断。无法从公开信息区分政策是隐私保护、国家安全还是纯贸易壁垒时，按制度目标分别表述，不合并为统一成本参数。
